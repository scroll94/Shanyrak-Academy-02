# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Статический сайт онлайн-школы «Шаңырақ Code» (подростки 14–18 лет: программирование и ИИ, математика, создание игр). Хостинг — GitHub Pages из ветки `main`, корень репозитория. Язык сайта и общения с владельцем — русский, отдельные слова на казахском (`lang="kk"`).

## Команды

Сборки, линтера и тестов в репозитории нет: файлы правятся напрямую и отдаются как есть (`.nojekyll`).

Локальный просмотр — любой статический сервер из корня:

```bash
python3 -m http.server 8000
```

Открывать через `http://`, а не `file://`: карточки грузят соседние страницы в `<iframe>` и общаются с ними через `postMessage`.

Если из среды закрыты `cdnjs.cloudflare.com` и `cdn.jsdelivr.net` (в облачных сессиях так бывает), 3D и анимации не загрузятся. Тогда для проверки в браузере ставят те же версии из npm (`three@0.186.0 gsap@3.13.0 lenis@1.1.13 cannon-es@0.20.0`) и подменяют CDN-адреса локальными файлами через `page.route()` в Playwright. Адреса CDN в самих файлах при этом не меняют.

## Архитектура

Каждая страница — один самодостаточный HTML-файл: стили в `<style>`, скрипты инлайн, библиотеки с CDN.

`index.html` — главная. Внутри три независимых блока скриптов, порядок важен:

1. **Основной скрипт** (обычный, после GSAP/Lenis): навигация, плавная прокрутка, карточки, окно «Развернуть», вопросы, форма заявки, закрепление юрты. Переменная `motion` истинна, только если загрузились GSAP с плагинами и не включено «уменьшить движение»; без неё страница обязана работать и быть полностью видимой. Анимации появления «взводятся» функцией `arm()` при первом действии посетителя — до этого страница показана в готовом виде.
2. **Мини-уроки** (`// ===== Мини-уроки`): бот, парабола, игра. Без библиотек и без зависимости от первого скрипта. Здесь же обработчик `[data-pick]` — любая ссылка с этим атрибутом подставляет направление в `#f-dir` формы.
3. **3D-сцены** (`<script type="module">`, Three.js): шаңырақ в герое, иконки у заголовка направлений, юрта. Сцены ниже экрана создаются лениво (`whenNear`) и рисуются только пока видны.

Связи между блоками, которые не видны из одного места:

- **Юрта**: основной скрипт пишет прогресс прокрутки в `window.__yurt.p` (0…1), 3D-сцена читает его и собирает юрту. Пороги этапов — массив `yMarks`.
- **Шаңырақ на телефоне**: место и размер задаёт CSS-переменная `--orb` на `.hero`; сцена читает их с блока `.hero-fallback` (он скрыт через `visibility`, не `display`, именно поэтому). Формула `--orb` подобрана так, чтобы заголовок и обе кнопки помещались на первом экране телефона, — при изменении высоты плашки героя константу в формуле нужно пересчитать.
- **Юрта на узком экране** вписывается в свободное место над `.yr-panel`: 3D-сцена меряет плашку и следит за ней через `ResizeObserver`.
- **Изменение высоты страницы** (вкладки мини-уроков, вопросы, форма) требует `ScrollTrigger.refresh()`, иначе закреплённая юрта встанет не на место. Правило `html.lenis { scroll-behavior: auto; }` обязательно по той же причине.
- **Карточки направлений** показывают `watch.html`, `tesseract.html`, `physics.html` в `<iframe>` с параметром `?card` (упрощённый режим без интерфейса). Главная шлёт им `postMessage({ active })`, чтобы они не рисовали кадры за экраном; часам ещё `{ hold }`. Кнопка «Развернуть» открывает ту же страницу без `?card` в `<dialog>`.
- **Плавающая кнопка WhatsApp** прячется над героем, мини-уроками и формой (список селекторов в основном скрипте).

Форма заявки ничего не отправляет на сервер: собирает текст и открывает `wa.me`. Это отражено в `legal.html` — при изменении формы, появлении аналитики или сторонних сервисов документы нужно обновить.

## Ограничения, которые легко нарушить

- **Только проверяемые факты.** Цен, отзывов, имён преподавателей, расписания и числа учеников на сайте нет, и придумывать их нельзя. Источники фактов — текущие тексты и `legal.html`. Незаполненные реквизиты в `legal.html` помечены `<mark class="fill">` — их вписывает только владелец.
- **Владелец сознательно сокращал текст.** Новое добавлять коротко или в интерактиве, а не абзацами.
- **Полный адрес сайта** `https://scroll94.github.io/Shanyrak-Academy-02/` зашит в мета-теги и JSON-LD `index.html` и в `404.html`; от него зависит превью ссылки в мессенджерах.
- **Номер WhatsApp** `77055823688` повторяется во всех файлах.
- **Поля ввода — не меньше 16px**, иначе iPhone увеличивает страницу при фокусе.
- **Без lookbehind в регулярных выражениях** и других конструкций, которые не разбирает Safari на iOS 15: синтаксическая ошибка роняет весь блок скрипта.
- Палитра и шрифты — переменные в `:root` (`--night`, `--gold`, `--sky`, `--felt`, `--milk`; Unbounded для заголовков, Onest для текста). У каждого направления свой `--accent`: золото — код, бирюза — математика, красный — игры.
