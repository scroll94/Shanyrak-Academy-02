# Шаңырақ Code

Сайт онлайн-школы для подростков 14–18 лет: программирование и ИИ, математика, создание игр. Первый урок бесплатный, заявки уходят в WhatsApp.

Адрес: **https://scroll94.github.io/Shanyrak-Academy/**

## Что на странице

Одна длинная страница, всё появляется при прокрутке:

1. «Нажми старт»: золотой 3D-шаңырақ с лучами-уықтар на тёмной сцене.
2. **Код и ИИ**: терминал печатает первую программу, при прокрутке собирается Telegram-бот, нейросеть показывает, как угадывает слово.
3. **Математика**: живой график с ползунками, теорема Пифагора клетками.
4. **Создание игр**: мини-игра, уровень собирается из падающих блоков.
5. **Чему мы учим создавать**: три интерактивные работы — механические часы, лаборатория чёрной дыры и 3D-сайт про защиту леса.
6. Уровень 1: 3D-юрта собирается при прокрутке.
7. Кнопка «СТАРТ» и подвал.

## Файлы

- `index.html` — главная.
- `watch.html` — механические часы на Three.js с разборкой.
- `blackhole.html` — гравитационное линзирование на шейдере.
- `forest.html` — учебный концепт сайта про лес (организация вымышленная).
- `assets/` — фотографии из Wikimedia Commons (авторы в подвале).
