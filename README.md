# Шаңырақ Code

Сайт онлайн-школы для подростков 14–18 лет: программирование и ИИ, математика, создание игр. Первый урок бесплатный, заявки уходят в WhatsApp.

Адрес после включения GitHub Pages: **https://scroll94.github.io/Shanyrak-Academy-02/**
(Settings → Pages → Branch: `main`, папка `/ (root)` → Save).

## Что на главной

1. **Первый экран**: 3D-шаңырақ, заголовок, кнопки «Записаться» и «Попробовать мини-урок». На телефоне всё помещается без прокрутки.
2. **Три направления**: карточки с живыми 3D-сценами (часы, тессеракт, физика) и кнопкой записи.
3. **Мини-уроки**: чат-бот, которому меняешь код; парабола, которую проводишь через звёзды; игра, где числа в коде меняют прыжок и скорость.
4. **Учёба — как юрта**: 3D-юрта собирается при прокрутке, каждая деталь — этап обучения.
5. **Частые вопросы**.
6. **Запись**: форма собирает сообщение и открывает WhatsApp. На сервер ничего не отправляется.

## Файлы

- `index.html` — главная: вся вёрстка, стили и скрипты в одном файле.
- `watch.html`, `tesseract.html`, `physics.html` — 3D-сцены из карточек; открываются и отдельно.
- `legal.html` — политика конфиденциальности, согласие, пользовательское соглашение.
- `404.html` — страница «не найдено».
- `assets/` — иконки сайта и картинка-превью ссылки `og.jpg` (1200×630).
- `.nojekyll` — GitHub Pages отдаёт файлы как есть.

Сборки нет: файлы правятся напрямую. Библиотеки (Three.js, GSAP, Lenis, cannon-es) и шрифты грузятся с CDN.

## Что менять руками

- **Номер WhatsApp**: поиск по `77055823688` во всех файлах.
- **Адрес сайта**: если сайт переедет, замените `https://scroll94.github.io/Shanyrak-Academy-02/` в `index.html` (мета-теги и данные для поисковиков) и `404.html`. От полного адреса зависит превью ссылки в мессенджерах.
- **Реквизиты**: в `legal.html` красным отмечены места, которые нужно заполнить (наименование ИП/ТОО, ИИН/БИН, адрес, почта, срок хранения).
- **Вопросы и ответы**: раздел `id="faq"` в `index.html`.
- **Картинка-превью**: `assets/og.jpg`. После замены мессенджеры обновят её не сразу, у них свой кэш.
